Cryptographic Protocols & Architectural Guarantees

Security Layer Cryptographic Standard Operational Purpose Tamper Survivability
Digital Signatures Ed25519 (RFC 8032) Signs every physical custody handover event by authenticated custodians. 128-bit security level; non-repudiation guaranteed.
Block Hashing SHA-256 (FIPS PUB 180-4) Chains consecutive block headers via immutable prev_hash links. Second preimage and collision resistant.
Event Tree Integrity Binary Merkle Tree Rolls up all custody events inside each block into a cryptographic Merkle root. Detects single-bit event alteration, deletion, or injection.
Layer 1 Steganography Zero-Width Unicode Invisible binary bit stream (ZWSP, ZWNJ, ZWJ) embedded in question paper text. Survives digital copy-paste; stripped by manual retyping.
Layer 2 Steganography Syntactic Permutations Base-4 lexical and stylistic variations across instructions and questions. Survives manual retyping and basic OCR.
Layer 3 Watermarking Visual Micro-Pattern 16-bit binary micro-cell grid rendered in page margins and faint watermarks. Survives screen photography and print-and-scan degradation.
